# ADR 0002: Licensing

**Status:** open, owner decision required. The repository currently has no licence file, so all rights are reserved. Options: Apache-2.0 (patent grant, industry friendly), MIT (simplest), or keep private/proprietary while engaging a potential industry partner. The repository is already public, so anyone can read it but nobody is granted rights; agree terms with any university or employer involved before choosing. Do not add a licence until decided.
