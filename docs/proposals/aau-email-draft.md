**Subject:** Request: one supervised robot logging session on heat and dust operating limits

Dear [name],

I am Huda Mueen. I have built Dhill, open source software (Apache License 2.0) that decides, for an outdoor ground robot, a site and
an hour, whether the robot should run at full speed, run slower, or rest in the shade, and names the component
that limits it. It runs on eleven years of recorded weather for six UAE sites, and its predictions have been
tested in two preregistered evaluations on simulated robots.

It has one gap I cannot close alone: every robot profile in it is built from datasheets and assumptions, and
every test so far uses a simulated robot. Before anyone relies on it, it has to be checked against a real robot.

I would like to ask the robotics programme for:

1. one robot the programme already operates outdoors (a Clearpath Jackal, a Husky or similar), for about three
   working days within six weeks, with no modification (sensors attached externally or read from its logs);
2. one supervised logging session, following a written protocol and safety stops agreed in advance; and
3. a senior robotics supervisor to approve the protocol and sign the prediction for the validation day before
   it is run.

No purchase is required. The programme keeps all robot data. The result is reported whether it confirms the
model or not, and a failure is useful: it shows which assumptions were wrong.

The two page proposal is attached, and the code and documents are at https://github.com/hudasol/dhill
(release v0.6.0). I would be glad to present it in person.
